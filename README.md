# 超级记事本 (SuperNotebook)

一款专为 Windows 用户定制的**现代化多文件数据收纳与智能 AI 助手桌面程序**。
特别适合用于分类管理个人网址、账号账密、零碎记录和日常备忘，内置 ReAct 物理连环接管 Agent。

## 🌟 核心硬核特性

### 1. 📂 隔离式专仓存储
所有的笔记、分类文件夹均永久、安全地保存在程序同级目录的 `data` 独立数据文件夹内，绝不污染系统目录与根执行路径，保持工作空间极致清爽。

### 2. 🌲 支持折叠的树形分类目录
* 采用多层级、可收起的二级树状卡片式管理。
* 单击分类文件夹（如 `理财`、`网站`）可以一键流畅地**展开/折起收纳**底下的所有子笔记，完美解决海量零散记录时的视觉疲劳。

### 3. 🖱️ 极简物理文件管理
* 右键左侧树中的任意笔记或分类文件夹，即可触发极简菜单：支持 `📝 重命名`、`➡️ 移动文件`（支持跨目录移动与自动自建新分类）、`🗑️ 删除`（带双重二次弹窗确认，安全保底）。

### 4. 🔗 网址交互深度调优
* **自动识别高亮**：打字时自动采用正规表达式检测文本中的 `http://` 或 `https://` 网址，并以科技蓝下划线高亮显示，不影响正常输入。
* **⚡ 双击秒开**：直接在编辑器内**双击**高亮网址，程序会自动调用系统默认浏览器一键飞速秒开网页！

### 5. 🔍 跨文件穿透全文检索与高亮联动
* 顶部全局搜索框支持穿透 `data` 下所有 `.txt` 的文本内容，并弹出精美检索面板。
* 选择任一匹配行后，编辑器自动为您跨笔记跳转并加载，**高亮全文所有匹配关键词，并自动滚屏聚焦直达第一处匹配位置**，附带“上一个/下一个”联动切换。

### 6. 👁️ 一键敏感信息“防窥脱敏遮罩”
* 顶端一键开启 `👁️ 脱敏`。系统会智能将全文的 URL 链接、password 密码字符进行星号 `***` 遮罩。
* **安全色锁定**：在脱敏开启期间，**自动切断并静默任何“自动保存”动作**，确保您的真实物理 TXT 文件绝不会被遮罩字符意外覆写！

### 7. ✍️ 微软雅黑排版与多行自适应输入框
* **微软雅黑排版**：徹底解决了西文字体由于 Windows Font Fallback 导致的中文字符及逗号 `，`、句号 `。` 浮在行中间漂移的难看缺陷。
* **智能自适应高度输入框**：AI 助手聊天输入框引入“物理换行+微软雅黑自折行字宽”双轨感应计算。**无论是一个字一个字打，还是 Ctrl+V 直接鼠标粘贴一长段文字，框体高度都会在 1 毫秒内自适应平滑变高（限制 5 行）**。
* **快捷按键**：`Enter` 一键发送（发送后高度重置为清爽单行），`Shift+Enter` 触发正常换行。

### 🧠 8. 内置大模型 AI 助手（全仓物理接管级 Agent）
接通任意 OpenAI 兼容大模型 API（如 SiliconFlow 硅基流动、DeepSeek 等），右侧一键展开 `🤖 AI 助手`：
* **🔍 在线模型一键拉取**：在 AI 配置中输入 API 地址和 Key 之后，点击 `可用模型`，自动在后台拉取接口商提供给您的所有可用模型型号，**双击即可一键回填**，免去手动输入的烦恼。
* **🔄 连环自主决策（Multi-Turn Loop）**：大模型拥有了跨笔记阅读的超能力，并被赋予了直接操纵您磁盘文件树和主编辑器的 Action 指令。如果您对它说：*“读一读账号下的中邮.txt，分析完把里面的密码单独提出来，在理财下新建一个同花顺笔记写进去，最后把账号空文件夹删了”*。
  * 引擎会自动进行**多轮自主连环迭代呼叫**，自动在向您分段播报流程的同时，自主完成多路径写盘和空文件夹删除！
* **🧹 一键净化调试日志**：点击 `🧹 清理日志`，一键抹除所有系统执行过程，只留纯净的人机对话。

## 🚀 快速开始

### 方式 A：免安装双击直接运行（最推荐，适合分发与日常使用）
我们已经为您准备好了高度自包含、零依赖、无黑屏终端干扰的 Windows 独立 `.exe` 可执行程序。
1. 前往项目的 `dist` 目录或 [Releases](https://github.com/your_username/SuperNotebook/releases) 页面下载 **`main.exe`**。
2. 建议在您的电脑上新建一个文件夹（例如命名为 `我的超级记事本`），将 `main.exe` 放入其中。
3. 直接双击运行它！

*注：程序启动后会在同级自动创建 `data` 文件夹用于存放您的笔记，切勿将其散乱丢在杂乱的系统或桌面路径下运行。*

### 方式 B：从源码调试运行
1. **环境克隆**：
   ```bash
   git clone https://github.com/your_username/SuperNotebook.git
   cd SuperNotebook
   ```
2. **安装依赖**：
   ```bash
   pip install customtkinter pyinstaller
   ```
3. **运行源码**：
   ```bash
   python main.py
   ```
4. **重新打包（生成无黑屏单文件 EXE）**：
   ```bash
   pyinstaller --noconsole --onefile --icon=app_icon.ico main.py
   ```
